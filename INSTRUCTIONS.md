## Operating Instructions

### 1. Adding Guests
To recognize a new person, simply place a clear photo of them in the `known_people/` folder.
* **Format:** `Name.jpg` (The filename becomes the spoken identity).
* **Supported formats:** .jpg, .png, .jpeg.

### 2. Execution
Run the system using the following command:
* cd Documents/smart_door 
* source env/bin/activate 
* python smart_door.py
